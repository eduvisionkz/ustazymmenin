# Жаңыл апайға алғыс

Ұстаздар күніне арналған сайт. Өмірбаян, Назеркенің жеке мақаласы, 2009 жылғы ортақ сынып суреті, көркем композиция және таңдалған фотогалерея, шәкірттердің естеліктері мен фотосуреттері. Жаңа материалдар бірден жарияланады. Әкімші қажет болса естелікті сайттан алып тастай алады.

## Қосу реті

1. ЖАҢА тегін Supabase жобасын ашыңыз (Talpyn жобасын өзгертпеңіз). Database → SQL Editor ішіне `setup.sql` толық мәтінін көшіріп, Run басыңыз.
2. Authentication → Providers → Anonymous Sign-ins қосыңыз. Email provider де қосулы болсын.
3. Authentication → Users ішінде өзіңізге email/password аккаунтын жасаңыз. `grant-admin.sql` ішіндегі `YOUR_EMAIL_HERE` сөзін сол email-ге ауыстырып, SQL Editor ішінде Run басыңыз.
4. Project Settings → API Keys бөлімінен **Project URL** және **publishable key** мәндерін алып, `src/supabase.ts` ішіндегі екі жолға енгізіңіз. Service role немесе secret key қолданбаңыз.
5. Барлық файлдарды жаңа GitHub репозиторийінің түбіріне жүктеңіз. `.github/workflows/pages.yml` файлы да жүктелгенін тексеріңіз; ZIP архивін бір файл күйінде жүктемеңіз.
6. GitHub репозиторийінде Settings → Pages → Build and deployment → Source: GitHub Actions таңдаңыз. Actions бөлімінде Publish GitHub Pages сәтті аяқталған соң сайт сілтемесін ашыңыз.
7. Сынақ естелігін фотомен жіберіңіз. Ол бірден көрінгенін тексеріңіз. Әкімші беті: сайт адресінің соңына `?admin` қосыңыз. Содан соң Facebook-те бөлісіңіз.

## Не белгілі және не жетіспейді

Негізгі мазмұн құжаттар мен Назеркенің мақұлдаған мақаласынан енгізілді. Бұл жинақта нақты Supabase жоба кілттері жоқ; олар қосылмайынша пікірлер мен фото жіберілмейді. GitHub аккаунтына жариялау автоматты түрде жасалмаған.

## Қауіпсіздік пен шектеулер

Фото браузерде JPEG форматына қысылып, жеке Storage bucket ішінде сақталады. Бакет жалпыға ашық емес. Алғашқы тестте Anonymous Sign-ins және RLS ережелерін міндетті түрде тексеріңіз. Естеліктер мен фотолар алдын ала тексерілмей жарияланады. Қоғамдық формаға спам келуі мүмкін; қажет болса әкімші бетінде материалды алып тастаңыз, ал белсенді қолдану басталса CAPTCHA және серверлік шектеу қосыңыз. Supabase тегін жобасы ұзақ уақыт белсенділік болмаса уақытша тоқтауы мүмкін.

Назеркенің жеке портреті сайтқа енгізілмеген. Галереяда Жаңыл апайдың бес жаңа суреті бар; балалардың және отбасындағы жақын кадрлар енгізілмеген. Фотосуреттердің файлдары өңделмеген, тек сайттағы көрсетілу тәсілі өзгертілген.
